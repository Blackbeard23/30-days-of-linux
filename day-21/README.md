## What I Learned

- `find` - used to find files or folders matching a particular search pattern. It searches recursively
```sh
#find a file or folder name
find . -name '*.txt'

#find only directories
find . -type d

#find only files
find . -type f

# to find only directories with 'E' in it name
find . -type d -name '*E*'

# for case insensitive
find . -type d -iname '*E*'

# or
find . -type d -iname 'E*' or -name 'G*'
```
